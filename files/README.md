# `files/` 目录数据说明

本目录下的 `2025/`、`2026/` 是 A 股全市场分钟级行情数据。`stock_transformer.py` / `train_sft.py` / `train_grpo.py` 是建模代码。

> 注：每个 CSV 文件名只编码了 **交易所 + 6 位证券代码**，没有公司中文名。
> 想得到 "代码 → 公司名" 的映射，需要外挂一张全市场对照表（如 Tushare、AKShare、Wind、东财数据等导出的 `stock_basic`）后做 left-join。本仓库内不带这张表。

## 5. 如何把 "文件名 → 公司名" 这张表补齐

工作区目前只有代码而没有名称对照。常见做法：

1. **离线表**：从 Tushare / AKShare 导出一张 `stock_basic.csv`，含 `code, name, list_date, industry, exchange`，按 `(交易所前缀, 6 位代码)` left-join 上来。
2. **在线接口**：用 `akshare.stock_zh_a_spot_em()` 或 `tushare.stock_basic()` 临时拉一份。
3. **批量解析**：如果将来你把对照表放到 `files/stock_meta.csv`，记得列至少有：

   ```csv
   exchange,code,name,board,list_date,delist_date
   sh,600000,浦发银行,沪市主板,1999-11-10,
   sz,000001,平安银行,深市主板,1991-04-03,
   bj,920000,...,北交所,...,
   ```

   `(exchange, code)` 是唯一键，对应文件名 `f"{exchange}{code}.csv"`。

## 6. 与建模代码的关系

- `stock_transformer.py`：单层截面 Transformer，输入 `(N, F)`，输出每只股票的 `[0,1]` 分数。
- `train_sft.py`：SFT 训练；目前用 `make_placeholder_samples` 占位。把 `load_samples()` 替换成基于本目录数据的真实加载（按日期对齐截面、特征工程后输出 `(x, y)`）即可。
- `train_grpo.py`：在 SFT 的基础上做 GRPO 微调；策略为 `Dirichlet(α = α_base + α_scale · score)`，输出横截面权重 `w ~ Dirichlet(α)`。

横截面建模数据准备建议：
1. 按上面表 4 选一个池子（如"全市场 A 股"或"沪深主板 + 创业板"），用代码段过滤。
2. **务必剔除 `sz07x` / `sz08x` 临时代码**。
3. 频率上：1 分钟做高频日内特征，15 分钟/30 分钟做相对低频或 label 计算。
4. 时间上：2025 全年做训练，2026 年初至今做 OOS 验证。
