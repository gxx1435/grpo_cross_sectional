# CSI500 / SP500：Diffusion · FM · SS-FM 二十种子稳定性汇总

## 设定

| 项 | 内容 |
| --- | --- |
| 生成模型 | Diffusion / FM / SS-FM |
| 市场 | CSI500 Top30；SP500 Top30 |
| G | {8, 32, 64, 128} |
| seeds | {1…20}；每日噪声 `hash(date, seed)` |
| Alpha / ckpt | 冻结最新（不训练） |
| Meta | G 条样本 ∪ Teacher（MVO / MaxSharpe / RiskParity）→ 再聚合 |
| Pure（无 Teacher） | 仅 G 条生成样本 → 再聚合；**仅 CSI500 本轮有完整三模型** |
| 聚合 | Pred-Utility / Mean / Top-k(k=3) / Softmax(τ=1.0)；同日同 G 同 seed 共享候选池 |
| 指标 | 全年 OOS **单利 Σ** 的 across-seed **mean±std** |
| CSI OOS | 2025-05…2026-05（≈245 日） |
| SP OOS | 2025-06…2026-05（≈235 日） |

机器可读总表：[`diffusion_fm_ssfm_20seeds_stability_master.csv`](diffusion_fm_ssfm_20seeds_stability_master.csv)

---

## 1. 总览结论

1. **CSI Meta Pred-Utility**：Diffusion ≫ SS-FM > FM；G↑ 三者均升，Diffusion@128 ≈ **0.88±0.23**。
2. **CSI Pure Pred-Utility**：去掉 Teacher 后 Diffusion@128 ≈ **0.90±0.26**，与 Meta 接近 → Diff 优势主要来自样本多样性+选仓。
3. **CSI Mean**：三家挤在约 **0.50–0.55**，方差远小于 Pred-Utility。
4. **SP Meta Pred-Utility**：SS-FM / FM 小 G 最好（约 **0.08**）；Diffusion 全负，且 **G↑ 更差**（@128 ≈ **−0.17**）。
5. **SP Mean/Softmax**：SS-FM 稳在约 **0.07**；FM / Diffusion 接近 0 或略负。
6. **跨市场**：同口径下 CSI 机会厚、SP 薄；Diffusion 排序翻转。
