## 实验设定

- Walk-forward 测试月 2025-05 … 2026-05（2026-05 分钟数据只到 05-08）。
- Alpha：**冻结复用** `results_alpha_prediction_ablation` 的 `transformer_gated_residual_auction` BEST（含竞价 Gate Residual Fusion，**不重训 SFT**）。
- Store：AblationStore F=62；分钟窗 `M_{D-10:D-1}`；竞价 D 日 09:25 九维。
- 标签 / 回测：`y = log(Close_D / Open_D)`，`return_type=log`，cost_bps=3.0。
- 配权=**Top30**（按 ŷ），long-only simplex，max_weight=0.15。
- OOS=`strict_fixed_oos`：每月单独跑，月内不周五重训。
- Teacher：MVO / MaxSharpe / RiskParity；Kelly 仅作 baseline。
- G 网格完整写入：8 / 16 / 32 / 64 / 128。

## 分析

分析主线是 **冻结 Gated Residual+Auction Alpha → Top30 → Teacher 基线 / 组合生成 / RL / G 网格**。
缺测单元格为 `-`，不补 0。

### Teacher
- 全年累计净收益最高: `Equal Weight` = 0.5616。
- Sharpe 最高: `Risk Parity` = 2.3853。
- Equal Weight 收益 `0.5616` / Sharpe `2.3836` / 换手 `0.0265`。
- Risk Parity 收益 `0.5526` / Sharpe `2.3853`。
- MVO / Kelly 同路径点估计收益 `0.2897`，换手高（≈0.94）。

### Teacher 配权相对 FM / Pure SS-FM
- 口径：以下累计净收益均为 **单利 Σ net_return**（非复利 `∏(1+r)−1`）。
- 累计净收益排序：FM `0.4903` > Risk Parity `0.4593` > Pure SS-FM `0.3736` > MaxSharpe `0.3694` > MVO `0.3261`。
- Sharpe：Risk Parity `2.3853` / FM `2.1480` 领先；Pure SS-FM `1.3309`；MaxSharpe `1.1874`；MVO `0.8746`。
- 换手：Risk Parity 极低（`0.0548`）；MVO/MaxSharpe 很高（≈0.92–0.94）；FM/SS-FM 居中（`0.4930` / `0.6675`）。
- 结论：单利口径下 **FM 仍最优**，Risk Parity 接近；Pure SS-FM 弱于二者但强于 MVO/MaxSharpe；高换手 Teacher 单利总分也明显落后。

### G=32：Teacher 相对 FM / SS-FM
- 口径：单利 Σ；生成模型固定 **G=32**；Teacher 无 G。
- 累计净收益排序：SS-FM G=32 `0.6084` > Risk Parity `0.4593` > FM G=32 `0.3705` > MaxSharpe `0.3694` > MVO `0.3261`。
- 要点：**SS-FM G=32**（`0.6084` / Sharpe `2.2998`）显著高于 FM G=32（`0.3705` / `1.5171`）与全部 Teacher；Risk Parity（`0.4593`）仍强于 FM@32。
- 与默认 G 对照：默认路径上 FM 优于 Pure SS-FM；切到 G=32 后 SS-FM 反超，说明 SS-FM 更吃候选宽度，FM@32 仍受 pred_utility winner's curse 拖累。

### SS-FM 相对 FM / Diffusion / MLP / Gaussian
- 全年累计净收益最高: `FM` = 0.5891。
- Sharpe 最高: `FM` = 2.1480。
- 最大回撤最小: `Diffusion` = 0.1310。
- 日均换手最低: `MLP` = 0.3555。
- 点估计对照：Pure SS-FM `0.3952` / `1.3309`；FM `0.5891` / `2.1480`；Diffusion `0.3173` / `1.0955`。

### PPO / GRPO 相对 Pure SS-FM
- Pure SS-FM 收益 `0.3952` Sharpe `1.3309` 换手 `0.6675`。
- SS-FM + PPO 收益 `0.2758` Sharpe `1.1293` 换手 `0.2858`。
- SS-FM + GRPO 收益 `0.5578` Sharpe `2.2487` 换手 `0.2808`。
- GRPO 在降换手的同时抬升了收益与 Sharpe；PPO 降换手但收益低于纯 SS-FM。

### G=32：PPO / GRPO 相对 Pure SS-FM
- Pure（Pure SS-FM G=32）单利 `0.6084`；PPO G=32 `1.0511`；GRPO G=32 `0.7166`。
- 相对 Pure：PPO 胜；GRPO 胜。
- Sharpe：Pure `2.2998` / PPO `2.8106` / GRPO `2.4533`。

### G=32 RL 消融：cand-PPO / SS-FM-init GRPO
- Pure SS-FM G=32 单利 `0.6084`；cand-PPO `0.8865`；GRPO-init `0.6779`。
- 相对 Pure：cand-PPO 胜；GRPO-init 胜。
- Sharpe：Pure `2.2998` / cand-PPO `2.1356` / GRPO-init `2.3644`。
- 换手：Pure `0.6492` → cand-PPO `0.2138` / GRPO-init `0.2739`。

### G 网格（SS-FM / FM）

- SS-FM 全年最优：`SS-FM G=32` = `0.7714` / Sharpe `2.2998`；对照默认 Pure（约 G=16）`0.4718`。
- FM 补跑全年最优：`FM G=16` = `0.6919` / Sharpe `2.1814`；G=32 `0.4045`、G=64 `0.3574`、G=128 `0.6015`。
- 同 G 对照：G=32 上 **SS-FM `0.7714` >> FM `0.4045`**；G=16 上本次 FM 复跑最强（`0.6919`），但加大 G 对 FM 无单调收益（峰值在小 G）。
- 解释：SS-FM 分 teacher 采样，加大 G 改善模式覆盖；FM 单一流上加大 G 等于在弱相关的 `pred_utility` 上更狠 argmax（winner's curse），仓位更尖、OOS 变差。
