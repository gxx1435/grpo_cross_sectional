## 0. 统一协议速查

| 项 | CSI500 | SP500 |
| --- | --- | --- |
| Alpha | 冻结 ablation `transformer_gated_residual_auction`（含集合竞价） | 冻结 Minute Transformer + Cross-Stock Attention |
| OOS | `strict_fixed_oos`，2025-05…2026-05（约 245 日） | `strict_fixed_oos`，2025-06…2026-05（约 235 日） |
| Teacher | MVO / MaxSharpe / RiskParity | 同左 |
| Meta | G 样本 ∪ Teacher → 再聚合 | 同左 |
| 无 Teacher 稳定性 | 仅 G 条生成样本 → 再聚合 | （本轮未新跑无 Teacher；有 Meta 稳定性） |

**四种聚合**（稳定性实验共用同日样本/Meta 池）：

1. **Pred-Utility**：`argmax_i (w_i·α̂ − ½λ w_i Σ w_i)`
2. **Mean**：候选权重等权平均
3. **Top-k**：按 utility 取 top-3 再平均（k=3）
4. **Softmax**：`Σ softmax(u/τ) w`，τ=1.0

**稳定性网格**：G∈{8,32,64,128}，seed∈{1…20}，每日噪声 `hash(date, seed)`；表内为 across-seed **mean±std**。

## 1. 总览结论（先看这个）

1. **CSI500 机会厚、SP500 机会薄**：同口径 Softmax Meta 下，CSI 生成族约 **0.45–0.55**（全正），SP 约 **−0.05–0.07**（仅 SS-FM 明显为正）。
2. **排序跨市场翻转**：CSI 上 Diffusion 经常最好；SP 上 Diffusion 经常最差，SS-FM 相对最稳。
3. **Pred-Utility 会放大极端**：在 CSI Diffusion 上随 G 升至 ~0.88–0.90；在 SP Diffusion 上随 G **恶化**。Mean/Softmax 更稳、水平接近。
4. **Teacher Meta 对 SS-FM 不一定加分**：CSI 上 SS-FM G=32 **非 Meta**（0.61）碾压默认生成族；SS-FM G=32 **Meta Pred-Utility**（0.19）反而垫底。Softmax Meta 把 SS-FM 拉回 ~0.49。
5. **无 Teacher 稳定性**：CSI 上 Diff ≫ FM ≈ SS-FM（Pred-Utility@G=128）；Mean/Softmax 三家都挤在 ~0.51–0.55。
6. **RL（SP500 r06，3 seeds）**：cand-PPO 稳定优于 SS-FM Meta 与 GRPO-init。
7. **CSI Diff+PPO/GRPO G=32**：已开跑，仅完成约 2025-05 月并卡在 2025-06 缓存构造，**本汇总不含完整 RL 对照**。

## 5. 跨市场机制解读

| 现象 | CSI500 | SP500 |
| --- | --- | --- |
| Softmax Meta 水平 | 全体 ~0.5 | 贴近 0 / 略负 |
| Diff 角色 | 最好（尤其 Pred-Utility） | 最差（G↑ 更差） |
| SS-FM 角色 | Softmax 中游；非 Meta@32 很强 | Softmax / 小 G Pred-Utility 相对最优 |
| 选仓符号（Diff） | G↑ → Pred-Utility↑ | G↑ → Pred-Utility↓ |

机制概括：

1. **市场/Alpha 可预测厚度**决定绝对收益量级（CSI 厚、SP 薄）。
2. **生成先验质量**决定相对排序（CSI Diff 多样且可挑；SP Diff 先验差）。
3. **聚合器**决定是否放大错排：Pred-Utility 高收益高方差；Mean/Softmax 稳健。
4. **Teacher Meta** 对 SS-FM 在 CSI Pred-Utility 下可能引入不利候选，需与 Softmax / 非 Meta 对照解读。

## 7. 后续建议（可选）

1. **标准化主榜**：同市场固定 G（如 32）+ Softmax（或 Mean）为主指标；Pred-Utility 作辅助并报 seed std。
2. **SP Diffusion**：优先查 pred_utility 与次日实现效用的 rank IC（预期接近 0/负）；再考虑重训或弃用 Diff。
3. **CSI SS-FM Meta**：区分 Pred-Utility Meta（本轮偏弱）与 Softmax Meta / 非 Meta@32（偏强），避免混谈「Meta」。
4. **跨市场**：同一聚合器下报告「绝对水平 + 族内排序」两层，避免只比 Diff 单点。
5. **续跑**：完成 CSI `strict_fixed_oos_diff_rl_g32` 后补 Diff vs PPO vs GRPO 表，并入本汇总附录。
