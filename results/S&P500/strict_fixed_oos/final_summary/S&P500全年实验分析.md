## 分析

分析主线是 **Minute Transformer + Cross-Stock Attention → 组合生成 → RL 配权优化**。预测骨干只有 `standard_transformer`，没有 LSTM。
缺测单元格为 `-`，不补 0。

### SS-FM 相对 FM / Diffusion / MLP / Gaussian
- 全年累计净收益最高: `Pure SS-FM` = 0.0520。
- Sharpe 最高: `Pure SS-FM` = 0.4471。
- 最大回撤最小: `FM` = 0.0892。
- 日均换手最低: `MLP` = 0.1037。
- 点估计对照（拼接 OOS）：Pure SS-FM 收益 `0.0520` / Sharpe `0.4471` / 换手 `0.5442`；FM `-0.0232` / `-0.1813`；Diffusion `-0.0922` / `-0.5767`。

### PPO / GRPO 相对 Pure SS-FM
- Pure SS-FM 收益 `0.0520` Sharpe `0.4471` 换手 `0.5442`。
- SS-FM + PPO 收益 `-0.0117` Sharpe `-0.0706` 换手 `0.2902`。
- SS-FM + GRPO 收益 `-0.0140` Sharpe `-0.0938` 换手 `0.2889`。
- 若 RL 换手明显低于纯 SS-FM 而收益更高，优先解释为摩擦下降，而不是新的截面 alpha。
