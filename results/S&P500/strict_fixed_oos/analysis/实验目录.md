# 实验目录

## 三层文档（先看这里）

1. **当月 Top30**：`results/full/sequential_oos_weekly_retrain/test_month=YYYY-MM/实验分析.md`
1b. **当月全股池配权**：`results/full/sequential_oos_weekly_retrain/test_month=YYYY-MM/实验分析_全股池配权.md`（正本在 `results/full_universe/...`）
2. **全年 / 全样本（13 个月拼在一起）**：`results/full/analysis/` 下各文件夹的 `实验分析.md`
3. **总目录（本文件）**：`results/full/analysis/实验目录.md`

表头、行名、曲线颜色在实验开始前就写死。没跑的单元格是 `-`，图只画坐标轴和图例虚线。
每完成一个训练/回测单元（例如 A-lstm 的 VAL），会重写当月 + 族级文档，填入已有数字并据此写分析。

## 规模

- 全年总览: **1**
- 主实验族: **6**
- 消融/系统族: **12**
- 实验分析文档: **19**（每族一份 `实验分析.md`）
- 测试月: **13**（2025-05 … 2026-05）
- 主实验月度单元（不含周五重训）: **221**

- 训练/回测单元合计: **637**

分析文档按实验族计（18 份），不是按每个月每个模型各写一份。

## 全年总览

- [`全年总览`](全年总览/实验分析.md) 全年总览：2025-05 至 2026-05 全股池实验 — 13 个测试月拼接：LSTM minute-only Alpha → 生成模型（MLP / Gaussian / FM / Diffusion / SS-FM）→ SS-FM+PPO/GRPO。全股池配权、下一日 close-to-close。

## 主实验（全年汇总）

- [`M01_prediction`](M01_prediction/实验分析.md) 主实验 A：Alpha 预测骨干对比 — LSTM minute-only 预测下一日 close-to-close，作为全股池配权的 Alpha baseline（取代 gated_residual）。
- [`M02_portfolio`](M02_portfolio/实验分析.md) 主实验 B：组合构建基线对比 — 同一 primary Alpha（LSTM minute-only）全股池上的 5 种组合器。
- [`M03_generative`](M03_generative/实验分析.md) 主实验 C：生成权重模型对比 — MLP / Gaussian / Standard FM / Diffusion / SS-FM 在全股池 simplex 上生成候选权重。
- [`M04_rl`](M04_rl/实验分析.md) 主实验 D：SS-FM + PPO / GRPO — 冻结 Alpha，SS-FM 蒸馏后分别 PPO 与 GRPO；对照纯 SS-FM。
- [`M05_g_candidates`](M05_g_candidates/实验分析.md) 主实验 E：候选数 G — SS-FM 采样候选数 G∈{8,16}，看收益与采样耗时。
- [`M06_walkforward_oos`](M06_walkforward_oos/实验分析.md) 主实验 F：Sequential OOS Weekly Retrain 走步 — 仅 Sequential OOS：周五收盘后用已实现数据重训 primary+生成+RL，下周一生效。测试月 2025-05～2026-05。

## 消融与系统（全年汇总）

- [`X01_fusion_ablation`](X01_fusion_ablation/实验分析.md) 消融：融合方式 — 分钟-only / concat / 单向 cross-attn / 门控残差 H_hist + g⊙H_auction。
- [`X02_minute_vs_auction`](X02_minute_vs_auction/实验分析.md) 消融：分钟 vs 集合竞价 — 有无 A_D 竞价增量信息。
- [`X03_attention`](X03_attention/实验分析.md) 消融：Cross-Attention 诊断 — Q=H_hist, K=V=H_auction 的注意力统计，不编造热力图。
- [`X04_gate`](X04_gate/实验分析.md) 消融：门控分布 — g 的均值/分位，检验竞价通道是否被学到。
- [`X05_fm_vs_diffusion`](X05_fm_vs_diffusion/实验分析.md) 消融：Flow Matching vs Diffusion — MLP、高斯、标准 FM、扩散、单纯形 SS-FM 对照。
- [`X06_ppo_vs_grpo`](X06_ppo_vs_grpo/实验分析.md) 消融：PPO vs GRPO — 同初始化、同奖励，只换更新算法。
- [`X07_g_curves`](X07_g_curves/实验分析.md) 消融：G–收益–耗时曲线 — 从主实验 E 抽出 G 曲线与采样时间。
- [`X08_leakage_audit`](X08_leakage_audit/实验分析.md) 系统：Leakage Audit — 高低严重级泄漏审计；FAIL 则该月 INVALID，不进入 final_summary。
- [`X09_gpu_time`](X09_gpu_time/实验分析.md) 系统：GPU 利用率与墙钟 — nvidia-smi 实测，不编造利用率。
- [`X10_prediction_distribution`](X10_prediction_distribution/实验分析.md) 诊断：预测分布 — ŷ 与 y 的分布、符号、分位。
- [`X11_top30_stats`](X11_top30_stats/实验分析.md) 诊断：Top30 命中与超额 — Hit@TopK、超额收益、覆盖重叠。
- [`X12_oos_mode`](X12_oos_mode/实验分析.md) 设定：OOS 模式说明 — Strict Fixed OOS 已弃用，只保留 Sequential Weekly Retrain。
